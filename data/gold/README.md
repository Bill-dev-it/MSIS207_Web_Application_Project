# Gold seed data

CSV data is generated by scripts/silver_to_gold/build_gold.py from cleaned
references plus explicitly custom demo entities. This folder no longer contains
only header templates. The current DBML schema determines column order.

Load into an empty application schema in this order:

1. companies
2. addresses
3. categories
4. engine_models
5. suppliers
6. aircraft
7. engines
8. products
9. seller_listings
10. product_engine_compatibility

Use UTF-8 CSV HEADER, map empty nullable fields to NULL, preserve explicit IDs,
and advance PostgreSQL identity sequences after import. The pipeline does not
connect to a database or perform that import.

Demo identities, addresses, commercial offers, asset assignment and compatibility
are custom. Source manufacturer/model references are FAA-derived. Price uses a
custom markup rule; stock is synthetic. All compatibility rows are marked demo.
Source parts metadata and demo flags appear in products.technical_specs.

Validate with `python scripts/silver_to_gold/build_gold.py --check`.
Rebuilding overwrites these ten managed CSVs deterministically; manual edits
should instead be made in the generator. Runtime tables are populated by the app.
